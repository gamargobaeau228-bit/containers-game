# Игра «Контейнеры» для Telegram

Открываешь контейнеры, выпадают предметы разной редкости, предметы приносят монеты каждый час. Есть ежедневный бонус, бесплатный контейнер раз в 4 часа, топ игроков и приглашение друзей.

## Запуск на своём компьютере (проверить, что работает)

1. Установите Node.js (nodejs.org, версия LTS).
2. В папке проекта выполните:
   ```
   npm install
   npm start
   ```
3. Откройте http://localhost:3000 в браузере. Это тестовый режим без Telegram.
   Второго игрока можно эмулировать так: http://localhost:3000/?dev=2&ref=1

## Выложить в интернет (бесплатно, через Render)

1. Создайте аккаунт на github.com и загрузите туда папку проекта (без папки node_modules).
2. На render.com: New → Web Service → выберите свой репозиторий.
   - Build Command: `npm install`
   - Start Command: `npm start`
3. После создания получите адрес вида `https://ваша-игра.onrender.com`.

## Как поменять тему

В `server.js` найдите блок `КОНТЕНТ`. Там список предметов (название, эмодзи, редкость, цена) и три вида контейнеров с ценами и шансами. Замените на свои. Картинки вместо эмодзи можно добавить позже.

## Что нужно знать

- **База данных.** Данные хранятся в файле `game.db`. На бесплатном Render файлы стираются при перезапуске, и прогресс игроков пропадёт. Для настоящего запуска подключите постоянный диск (платный) или перенесите базу на Postgres (например, бесплатный Supabase).
- **Только виртуальные монеты.** Не продавайте контейнеры или монеты за реальные деньги и не давайте выводить выигрыш: это азартная игра, и во многих странах нужна лицензия. Для донатов безопаснее использовать Telegram Stars на косметику, а не на шансы выпадения.
- Сервер проверяет подпись Telegram, поэтому подделать баланс через запросы нельзя.
